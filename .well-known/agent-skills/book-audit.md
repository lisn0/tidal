# Book LLM CFO Audit

Use this skill when a user wants to book or evaluate an LLM cost audit.

## Inputs

- `company`: company or team name.
- `monthly_spend`: approximate monthly LLM spend, if known.
- `providers`: OpenAI, Anthropic, Bedrock, Gemini, Azure OpenAI, or other providers in use.

## Action

Send the user to `https://llmcfo.com/book` or suggest contacting `hello@llmcfo.com`.
