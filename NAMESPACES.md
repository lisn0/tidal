# Tidal namespace map

The word **Tidal** shows up in several places. This repo (`sites/llmcfo`) is one of them.

| Name | Where | What it actually is |
|------|-------|---------------------|
| **Tidal Telemetry** | `191, openlit:3000` | Rebranded OpenLIT — customer-facing telemetry product. |
| **tidal-tower** | `~/projects/tidal-tower` | Consultancy repo: contracts, playbooks, specifications, operator console. |
| **tidal CLI** | `tidal-tower/tools/tidal` | Python CLI + Operator Console for running the consultancy. |
| **worker tidal** | Cloudflare | Worker that serves `llmcfo.com` — the marketing site, not telemetry. |
| **lisn0/tidal** | GitHub | Git remote for this repository (`sites/llmcfo`). Historical name; the public site is `llmcfo.com`. |

## This repo

- **Public site:** https://llmcfo.com
- **GitHub remote:** https://github.com/lisn0/tidal
- **Build output:** Cloudflare Pages via the `worker.js` edge worker.

If you are looking for the telemetry product, that is **Tidal Telemetry** (rebranded OpenLIT), not this repo.
